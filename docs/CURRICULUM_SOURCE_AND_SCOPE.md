# NihongoVertex curriculum source and scope

## Minna no Nihongo alignment

NihongoVertex uses the public structure of Minna no Nihongo Elementary I and II as an alignment layer for N5/N4. The official 3A Network description says the elementary series contains 25 lessons in Main Text I and 25 in Main Text II, for 50 lessons total, with sentence patterns, example sentences, conversation, exercises and practice. The application mirrors that 25 + 25 structure while writing its own explanations, examples, drills and quizzes.

## India / English / Tamil layer

The project supports a three-language learning layer:
- Japanese source labels and examples
- English explanations
- Tamil explanations

The exact wording of a commercial Indian translation/grammar-notes book is not reproduced. If the user supplies that edition as a file, the curriculum can be mapped lesson-by-lesson against it without copying protected passages into the app.

## N3-N1

Minna no Nihongo Elementary I/II does not itself provide a complete N3-N1 JLPT syllabus. NihongoVertex therefore uses an original advanced bridge for N3, N2 and N1, organized around grammar, vocabulary, reading, listening, kanji/word formation and exam practice.

## Content model

Every curriculum module has:
- objective
- grammar targets
- vocabulary themes
- reading/listening/speaking/writing skills
- original learning materials
- quiz coverage
- level and source-alignment metadata
